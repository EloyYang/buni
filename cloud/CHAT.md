# 부니 채팅

방 코드로 모여서(최대 5명) 대화하는 기능입니다. 로그인(Google)이 필요하고, 서버는 Firebase
**Realtime Database**를 씁니다. 다른 사람에게는 **닉네임 · 캐릭터 · 옷차림 · 대화 · 작업 모션**만
보이고, 어떤 세션에서 무슨 작업을 하는지는 전해지지 않습니다.

## 동작

- **채팅용 부니**가 사람마다 하나씩 따로 생깁니다. 기존 세션 부니(말풍선·권한 요청·게이지)와는 별개라
  작업 알림이 대화와 겹치지 않습니다.
- 채팅 부니의 모션은 내 세션들을 요약해 만듭니다: 하나라도 **작업 중**이면 작업 모션, 아니면
  **완료**된 세션이 있으면 완료 모션, 그 밖엔 대기. 이 값(`idle` / `working` / `done`)만 상대에게 갑니다.
- 방은 6자리 코드로 들어갑니다(`A–Z`·`2–9`, 헷갈리는 0·O·1·I 제외). 한 명이 "새 방 만들기"로 코드를 만들고
  다른 사람이 그 코드를 입력합니다.
- **닉네임**은 20자까지이고 비워 두면 고른 캐릭터의 이름(부니·우니 등)으로 표시됩니다(로그인 계정의 실명은 쓰지 않습니다). 방 안에서는 내 이름표를 눌러 그 자리에서 바꿀 수 있고 바로 다른 사람에게도 바뀝니다.
- 한 번에 **50자**까지 입력할 수 있고(넘치면 입력되지 않음), 말풍선은 글자 수만큼만 커지며 줄임표 없이 전부 보입니다.
- 말풍선은 새 메시지가 오면 약 9초 동안 보입니다. **대화 기록은 남기지 않습니다** — 메시지는 보낸 사람이 15초 뒤(또는 방을 나갈 때) 서버에서 지우고, 들어올 때 남아 있던 지난 메시지는 보이지 않고 지워집니다.

## 서버 설정 (한 번만)

1. Firebase 콘솔 → **Realtime Database → 데이터베이스 만들기** (위치는 싱가포르 `asia-southeast1` 권장,
   *잠금 모드*로 시작). Spark(무료) 요금제로 충분합니다.
2. **규칙** 탭에 [`database.rules.json`](database.rules.json) 내용을 붙여 넣고 **게시**.
3. `cloud-config.json`에 데이터베이스 주소를 추가합니다.

```json
{ "databaseURL": "https://<프로젝트>-default-rtdb.asia-southeast1.firebasedatabase.app" }
```

주소를 넣지 않으면 기본 주소(`https://<프로젝트 ID>-default-rtdb.firebaseio.com`, 미국 리전)를 씁니다.

## 데이터 구조

```
rooms/{CODE}/meta                 { owner, createdAt }
rooms/{CODE}/members/{uid}        { name, char, motion, equip{slot:id}, seen, joined }
rooms/{CODE}/messages/{pushKey}   { uid, name, text, ts }
```

- 클라이언트는 `members`와 `messages`(최근 40개)를 **Server-Sent Events** 스트림으로 실시간 구독합니다.
- 20초마다 `seen`(서버 시각)을 갱신하는 것이 생존 신호입니다. 75초 넘게 바뀌지 않으면 화면에서 뺍니다.
  90초 넘게 조용한 자리는 다른 사람이 지울 수 있습니다(규칙).
- **5명 제한**: 규칙으로는 인원을 셀 수 없어서 들어온 사람이 직접 확인합니다. 내 자리를 쓴 뒤 활동 중인
  사람들을 `joined`(서버 시각) 순으로 세워 내가 6번째 이후면 자리를 거두고 "가득 찼어요"를 보입니다.
  모든 클라이언트가 같은 기준이라 동시에 들어와도 가장 늦은 사람이 물러납니다.
  (개조한 클라이언트가 이 확인을 건너뛰면 5명을 넘길 수 있습니다 — 친구·팀용으로 충분하다고 보고 서버에서
  강제하지 않습니다.)
- 메시지는 읽기·쓰기 모두 **방 참여자만** 가능하고, 수정은 할 수 없으며 삭제는 보낸 사람(또는 60초 넘게 남은 것을 참여자가)만 할 수 있습니다(규칙).

## 알아둘 점

- 방 코드를 아는 로그인 사용자는 누구나 들어올 수 있습니다. 코드는 비밀번호처럼 다루세요.
- 메시지는 잠깐만 서버에 있다가 지워집니다. 다만 앱이 갑자기 꺼지면 그 메시지는 다음에 누가 들어올 때 정리됩니다. 빈 방(`meta`)을 정리하는 기능은 아직 없습니다.
- 무료 한도: 동시 연결 100개(= 동시에 접속한 기기 수 기준 약 50명, 기기당 스트림 2개). 사용자가 늘면
  Blaze로 올리거나 구조를 바꿔야 합니다.
