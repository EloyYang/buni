# 화면 실기 확인 체크리스트 (부니 1.9.1)

화면이 있는 PC에서 사람이 눈으로 하나씩 확인하는 표다. **이 문서는 코드·문구를 바꾸지 않는다.** 각 줄의 "기대 모습"과 다르면 O/X 칸에 X 와 메모를 남긴다. (작성 환경에서는 창을 띄워 보지 못했다 — 맨 아래 "이 환경에서 못 한 것" 참고.)

공통 기준
- **글자 잘림**: 버튼·라벨·카드 제목이 `…` 없이 끝까지 보이거나, 길면 의도한 말줄임(`…`)만 있다. 창을 가장 작게 줄여도 버튼이 가려지지 않는다.
- **색 대비**: 본문(`ink`/`ink2`)은 바탕(`bg`·`panel`) 위에서 또렷이 읽힌다(4.5:1 이상, `docs/design-system.md`). 보조 문구(`dim`)는 읽히되 약하다. 당근색 `#F28C2E` 는 주 버튼·선택 표시에만 보이고 그 위 글자는 어두운 `#1A1206`.
- 한/영 전환(설정 언어)을 바꿔 두 언어 모두 한 번씩 본다.

## 0. 화면 시험 `test_board_ui.py` 돌리기 (Windows 또는 Tk 가 되는 PC)

```bash
BUNI_UI_TEST=1 python3 -m unittest tests.test_board_ui      # 저장소 루트에서
```
- 필요: 화면 세션(원격·SSH 만으로는 안 됨), 파이썬 `tkinter`(Windows 설치형 파이썬에 포함).
- 임시 폴더(`BUNI_TEAM_HOME`)와 없는 `claude`(`BUNI_CLAUDE`)로 돌아 내 데이터·진짜 claude 를 건드리지 않는다. 창은 잠깐 깜빡일 수 있고 25초 안에 안 끝나면 멈춘 위치를 찍고 종료한다.
- 기대: `OK`(건너뜀 0). `skipped` 가 뜨면 `BUNI_UI_TEST=1` 을 안 줬거나 Tk 를 못 띄운 것 — 통과로 치지 않는다.
- 이 시험은 "오류 없이 그려지는지"만 본다. 모양은 아래 표로 눈으로 확인한다.
- 전체 시험 `python3 -m unittest discover -s tests -p "test_*.py"` 에서는 이 시험이 건너뜀 1개로 나오는 게 정상.

| # | 확인 | 기대 | O/X |
|---|---|---|---|
| 0-1 | 위 명령 실행 | `Ran 1 test … OK`, skipped 아님 | |

## 1. Pro 업그레이드 창: 체험 → 만료 → 키 입력 → 활성화

준비(맥·Windows 공통, 앱을 끈 뒤):
- 상태 파일 `pro.json`: 맥 `~/Library/Application Support/Buni/pro.json`, Windows `%APPDATA%\Buni\pro.json`. 고치기 전에 **복사해 백업**한다.
- 체험 중 보기: 파일을 지우고 앱을 새로 켠다(신규 14일. `state.json`/`shop.json` 이 있으면 기존 사용자 30일).
- 만료 보기: `pro.json` 의 `trial_start` 를 아주 옛 값(예: `1700000000`)으로 바꾸고 앱을 켠다.
- 활성화 시험: **진짜 키·진짜 공개키는 쓰지 않는다.** 임시 키 쌍을 저장소 밖에 만든다(`python3 tools/issue_license.py keygen --out <저장소 밖 경로>`, `tools/README.md`). 출력된 공개키 hex 를 환경변수 `BUNI_LICENSE_PUBKEY` 로 주고(코드 수정 없음) 앱을 그 환경에서 켠 뒤, 같은 임시 비밀키로 `issue --plan monthly --days 32` 한 키를 쓴다. 끝나면 임시 키·환경변수·`pro.json` 백업을 되돌린다.
- 창 열기: 맥 메뉴바 토끼 → `⭐ 부니 Pro (…)`, Windows 트레이/메뉴 `⭐ 부니 Pro...`. 설정의 Pro 구역 `플랜 보기 · 키 등록` 으로도 열린다.

브라우저로 `docs/index.html` 파일을 직접 연다(또는 로컬 서버). 데스크톱 너비와 폭 400px 안팎(휴대폰) 둘 다 본다.

| # | 확인 | 기대 모습 | O/X |
|---|---|---|---|
| 4-1 | 첫 화면 | 다크 바탕(`#1E1E24`), 토끼 마스코트 픽셀이 뭉개지지 않음, 제목·부제 읽힘 | |

## 이 환경에서 못 한 것

- 위 1~4 의 모든 항목: 이 작업 환경에는 화면 세션이 없어 맥 앱·Windows 앱·브라우저를 띄워 보지 못했다. 그래서 O/X 칸은 모두 비어 있다.
- `BUNI_UI_TEST=1 python3 -m unittest tests.test_board_ui`: 화면 없는 환경이라 실행해도 건너뜀이 되어 통과로 치지 않았다(0 항목).
- Windows 실기: 이 환경은 macOS 다. Windows 항목은 코드(`buni_pro_ui.py`, `buni_team_ui.py`)의 문구를 읽고 기대 모습을 적었다.
- 색 대비 수치 측정은 하지 않았다. 기준은 `docs/design-system.md` 의 값이다.
