직접 앱을 켜서 보는 방법

  • 바뀐 후(맥): 이 브랜치에서 swift build 후 ./build_app.sh(설치 옵션 없이)로 만든 앱을 실행 → 설정의 플랜 보기 · 키 등록(업그레이드 창), ⌃⌥S(스쿼드) → 사이드바 맨 위 📊 업무 현황.
  • 바뀌기 전(맥): 저장소를 건드리지 않으려면 git archive 9be345b^ | tar -x -C /임시폴더 로 옛 소스를 임시 폴더에 풀어 같은 방법으로 빌드(이 기능 자체가 이 커밋 이후에 일부 생겼으므로 보드 화면은 옛 소스에 없을 수 있음).
  • Windows: windows/buni.py 실행 → 트레이/설정에서 Pro, Ctrl+Alt+S 로 스쿼드 창. 옛 모습은 git show 9be345b^:windows/buni_pro_ui.py 로 옛 파일을 임시 폴더에 저장해 실행.
  • 사이트: docs/index.html 을 브라우저로 열기(현재). 옛 모습은 git show 9be345b^:docs/index.html > /임시폴더/old.html 후 열기.
