# 소액 유료 광고 계획안 (문서만 — 집행·지출 없음)

무료 채널(`schedule.md`)을 먼저 끝내고, **전환 경로가 실제로 동작한 뒤**에만 검토한다. 아래 수치는 시작 가정이며 업계 평균을 인용한 것이 아니다.

## 전제 조건 (모두 충족해야 시작)
- Stripe 링크와 라이선스 키 발급이 실제로 동작(구매 → 키 수령 → 앱에서 Pro 확인을 직접 테스트)
- Plausible이 사이트에 켜져 있고, 가격 섹션 "결제" 클릭을 목표(goal)로 설정
- 무료 채널 게시 후 2주 데이터 확보

## 예산
| 항목 | 범위 |
|---|---|
| 1차 실험 | 총 $100~150, 2주 (하루 $7~10) |
| 상한 | 월 $300. 이 이상은 1차 결과가 목표를 넘은 뒤 사용자가 다시 승인 |

## 채널 후보
| 채널 | 이유 | 비고 |
|---|---|---|
| Reddit Ads (r/ClaudeAI 등 관심사 타기팅) | 개발자 독자가 모여 있음 | 최소 입찰·계정 필요 |
| X Ads (Claude Code·AI 코딩 키워드) | 영상 A 활용 | 광고 심사 문구 확인 |
| 뉴스레터·커뮤니티 스폰서 슬롯 | 소액 고정가 | 개발자 대상 소규모 매체 |
| (보류) Google Ads | 검색어 수요가 불확실 | 1차 결과 후 |

## 목표 지표 (시작 가정)
- 광고 클릭 → 사이트 방문당 비용(CPC): $1 이하
- 사이트 방문 → 다운로드 클릭 전환: 10% 이상
- 체험 → 유료 전환은 서버가 없어 직접 측정이 어려움 → **Stripe 결제 건수 ÷ 광고비**로 대체 측정
- 목표 CAC: 연간 플랜 가격($24) 이하, 이상적으로 $12 이하

## 중단 기준
- 광고비 $50 지출 시점에 유료 결제 0건이고 다운로드 클릭 전환 5% 미만 → 소재·문구 교체 1회 후 재시도
- 교체 후 추가 $50에도 결제 0건 → 중단
- CAC가 $24를 2주 연속 초과 → 중단
- 환불·불만 문의가 눈에 띄게 늘면 즉시 중단하고 원인 확인
- 월 상한 $300 도달 시 자동 중단

## 소재
영상 A(15초), 이미지 1·2·4, 카피는 `intro.md`의 한 줄·짧은 소개. 과장·가짜 수치 금지, "무료로 시작, Pro는 선택"을 명시.

## 측정 방법
UTM(`utm_source=reddit&utm_campaign=ex1`)을 광고 링크에 붙이고 Plausible 소스 보고서로 확인. 앱 안에는 어떤 분석도 넣지 않는다.
