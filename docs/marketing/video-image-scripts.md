# 영상·이미지 스크립트

실제 앱 화면 녹화/캡처만 쓴다(목업·가짜 화면 금지). 사이트 히어로 데모는 실제 캐릭터 비율을 재현한 것이라 보조 소재로만 쓴다.

## 영상 A — 15초 가로형 (X/Threads/PH 갤러리)
| 초 | 화면 | 자막 KO / EN |
|---|---|---|
| 0–3 | 코드 편집기 옆 구석에서 토끼가 대기 | 딴짓하는 중… / Doing something else… |
| 3–6 | Claude Code에 프롬프트 입력 → 토끼가 타이핑 | 부니가 일해요 / Buni is on it |
| 6–10 | 권한 요청 말풍선 → 허용 클릭 | 터미널로 안 돌아가도 돼요 / No trip back to the terminal |
| 10–13 | 완료: 팔 번쩍 + 말풍선 | 끝났어요 ✓ / Done ✓ |
| 13–15 | 로고 + 주소 | {SITE_URL} |

## 영상 B — 30초 기능 훑기 (세로 가능, 쇼츠/릴스)
토큰 게이지 → 세션별 다른 캐릭터 2개 동시 → 상점에서 입어보기 → 덮개 닫음 아이콘(덮개 닫아도 계속 실행) → 채팅 말풍선. 마지막 3초: "기본 기능 무료 · Pro 월 $3" (결제 링크가 열린 뒤에만 가격 자막).

## 이미지
1. **히어로 캡처** — 화면 구석 토끼 + 말풍선 "완료 ✓" (캡션: 터미널 안 봐도 알아요)
2. **권한 요청** — 허용/전체 허용/거부 버튼이 보이는 장면
3. **캐릭터 6종 한 줄 정렬**
4. **가격표** — 사이트 가격 섹션 캡처(무료/월/연/평생). 결제 링크가 '준비 중'이면 게시 보류
5. **OG 이미지 1200×630** — 토끼 + "Buni for Claude Code"

## 제작 메모
- 녹화: macOS 화면 기록(⇧⌘5), Windows Xbox Game Bar(Win+G). 작업 내용이 보이면 코드·경로·이메일을 가린다.
- 음악은 라이선스 확인된 것만, 없으면 무음 + 자막.
