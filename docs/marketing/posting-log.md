# 외부 게시 시도 기록

기록일: 2026-10-28 · 담당: 웹·마케팅

## 판단
사전요구서 §9: 외부 게시는 "사용자가 이미 로그인해 두고 허용한 공식 도구"가 있을 때만 시도한다. 이번 작업에는 그런 도구가 지정되지 않았고 외부 전송이 금지돼 있어, **모든 채널에서 게시를 시도하지 않았다**(계정 생성·비밀번호 입력·인증 우회도 하지 않음). 가짜 URL은 적지 않는다.

## 사용자가 게시하려면
1. `{SITE_URL}`을 실제 주소로 바꾸고 `docs/site-config.js`에 Stripe 링크를 넣는다.
2. `schedule.md` 순서대로 `launch-posts.md` 원고를 해당 채널의 규칙에 맞게 다듬어 붙여 넣는다.
3. 게시 후 이 표에 성공 URL을 직접 적는다.
