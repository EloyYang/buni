## 1. 소개문

**한 줄**
Claude Code가 지금 뭘 하는지, 화면 구석의 픽셀 토끼가 알려줘요.

**짧게**
부니는 Claude Code 세션의 상태(생각 중 · 도구 사용 · 권한 요청 · 완료)를 화면 구석의 픽셀 토끼로 보여 주는 macOS·Windows 앱이에요. 터미널을 계속 들여다보지 않아도 돼요.

**보통**
Claude Code를 돌려놓고 다른 일을 하다가, 끝났는지 확인하려고 터미널로 돌아온 적 있죠? 부니는 세션마다 작은 토끼 패널을 화면 한쪽에 띄워서 생각 중인지, 권한을 기다리는지, 끝났는지를 몸짓과 말풍선으로 알려 줘요.

- 권한 요청이 오면 말풍선에서 바로 허용 · 전체 허용 · 거부
- 토큰 사용량 게이지
- 세션마다 다른 캐릭터, 작업이 끝나면 쌓이는 코인으로 꾸미는 상점
- 노트북 덮개를 닫아도 계속 실행, 방 코드 채팅(최대 10명)
- 앱에는 분석·원격 수집이 없어요

지금 있는 기능은 계속 무료예요. Pro(월 $3 / 연 $24 / 평생 $49)는 프로 캐릭터·컬러 변형과 클라우드 동기화를 열고, 개별 팩을 30% 할인해 줘요. 신규는 14일, 기존 사용자는 30일 Pro 체험이 있어요.

## 2. 런칭 글

**제목:** 부니를 만들었어요 — Claude Code 상태를 알려 주는 픽셀 토끼 🐰

Claude Code에 일을 맡겨 두면 자꾸 터미널을 확인하게 되더라고요. "아직 생각 중인가? 권한 기다리나? 끝났나?" 그게 번거로워서, 세션마다 화면 구석에 작은 토끼를 띄우는 앱을 만들었어요.

**어떻게 동작하나요**
Claude Code 훅이 이벤트를 로컬 파일에 적고, 앱이 그걸 읽어 토끼의 상태를 바꿔요. 별도 서버는 없어요.

**할 수 있는 것**
- 생각 중 / 도구 사용 / 권한 요청 / 완료를 각각 다른 모습과 말풍선으로 표시
- 권한 요청 말풍선에서 허용 · 전체 허용 · 거부
- 토큰 사용량 게이지
- 세션마다 다른 캐릭터와 코인 상점
- 덮개를 닫아도 계속 실행, 방 코드 채팅(최대 10명)
- macOS(Swift)와 Windows(Python) 모두 지원

**가격**
기존 기능은 그대로 무료예요. Pro는 선택이고, 월 $3 · 연 $24 · 평생 $49예요. 프로 캐릭터·컬러 변형, 클라우드 동기화, 개별 팩 30% 할인이 들어 있어요. 라이선스 키는 오프라인 서명 방식이라 서버 확인이 없어요.

써 보시고 부족한 점이나 가격에 대한 솔직한 의견을 주시면 큰 도움이 돼요.
