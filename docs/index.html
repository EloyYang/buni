가격

기본 기능은 계속 무료, 더 쓰고 싶다면 Pro

세션 패널, 상태 표시, 채팅 같은 지금의 기능은 그대로 무료예요. Pro는 아래 기능을 열어줘요.

  • 스쿼드 고급 기능 — 업무 예약, 여러 작업 병렬 실행 (기본 단일 작업은 무료)
  • 프로 캐릭터·테마 — 새 색상 캐릭터와 테마 (기존 캐릭터·테마는 그대로 무료)
  • 클라우드 동기화 — 새로 켜는 경우 Pro 필요. 이미 쓰던 동기화는 멈출 뿐 데이터는 지우지 않아요
