Buni 개인정보처리방침

시행일: 2026년 10월 27일

Buni(부니)는 Claude Code 작업 상태를 화면 구석의 픽셀 토끼로 보여주는 개인용 데스크톱 앱입니다. 이 문서는 앱이 어떤 정보를 사용하고 저장하는지 설명합니다. Google 로그인은 선택 사항이며, 로그인하지 않아도 모든 기본 기능을 쓸 수 있습니다. 로그인하지 않으면 아래 서버 저장은 일어나지 않습니다.

1. Google 로그인으로 받는 정보

다른 PC와 설정을 이어 쓰거나 채팅을 쓰려고 로그인할 때, 기본 로그인 권한(openid, email, profile)만 요청합니다. Gmail, 드라이브, 연락처 등 다른 Google 데이터에는 접근하지 않습니다.

정보사용 목적
계정 고유 ID내 데이터와 다른 사람의 데이터를 구분
표시 이름로그인 상태 표시 (채팅에서는 직접 정한 닉네임만 쓰고, 비워 두면 캐릭터 이름이 보입니다)
이메일 주소·프로필 사진Google 로그인 처리 과정에서만 쓰입니다. Buni의 서비스 데이터에는 저장하지 않으며, 앱 기능에도 사용하지 않습니다.

로그인 처리는 Google의 Firebase Authentication이 맡습니다. 이 과정에서 Google이 로그인 기록으로 계정의 이메일·이름·프로필 사진 주소를 자체 보관할 수 있습니다.

2. 서버에 저장되는 정보 (로그인한 경우에만)

항목내용보관
계정 연동코인, 산 아이템, 캐릭터별 착용 상태, 기기별 이번 달 토큰 사용량(레벨 계산용 숫자), 계정 ID, 표시 이름사용자가 삭제할 때까지
채팅방방 코드, 닉네임, 캐릭터·옷차림·레벨, 작업 모션(대기/작업 중/완료)방에 있는 동안만 (나가면 삭제)
채팅 메시지보낸 사람 ID, 닉네임, 메시지(50자 이내)약 15초 뒤 보낸 사람이 삭제 — 기록을 남기지 않습니다

저장하지 않는 것: Claude와의 대화 내용, 코드, 파일 이름, 어떤 작업을 하고 있는지, 사용 중인 프로젝트 정보. 채팅 상대에게는 작업 모션(대기/작업 중/완료)만 전달됩니다.

3. 이 기기에만 저장되는 정보

  • 설정, 단축키, 상점 상태 등은 이 기기에 저장됩니다.
  • Google 로그인 유지용 토큰은 macOS 키체인 또는 Windows 데이터 보호(DPAPI)로 암호화해 이 기기에 보관합니다.

4. 제3자 제공 및 이용 목적

정보는 위의 기능을 제공하는 목적으로만 사용합니다. 광고에 쓰지 않으며, 판매하거나 제3자에게 제공하지 않습니다. 데이터는 Google의 Firebase(Authentication, Firestore, Realtime Database — 채팅은 싱가포르 지역)에 저장됩니다.

5. 삭제와 로그아웃

  • 앱 설정의 로그아웃으로 이 기기의 로그인 정보를 지울 수 있습니다.
  • 앱 설정의 서버 데이터 삭제로 서버에 저장된 계정 연동 데이터를 직접 삭제할 수 있습니다.
  • Google 계정 설정(myaccount.google.com/connections)에서 Buni에 대한 접근 권한을 언제든 해제할 수 있습니다.

6. 문의

개인정보에 관한 문의·삭제 요청은 GitHub Issues로 남겨 주세요.

Buni Privacy Policy

Effective: October 27, 2026

Buni is a personal desktop app that shows your Claude Code status as a pixel rabbit in the corner of your screen. This page explains what information the app uses and stores. Signing in with Google is optional; every basic feature works without it. If you don't sign in, none of the server storage below happens.

1. What we receive when you sign in with Google

To sync your settings across PCs or to use chat, the app requests only the basic sign-in scopes (openid, email, profile). It does not access Gmail, Drive, Contacts or any other Google data.

InformationPurpose
Account unique IDTell your data apart from other people's
Display nameShow your signed-in state (chat uses only the nickname you choose; if empty, your character's name is shown)
Email address, profile photoUsed only while Google processes the sign-in. Not stored in Buni's service data and not used by any app feature.

Sign-in is handled by Google's Firebase Authentication, which may keep the account's email, name and profile photo address in its own sign-in records.

2. What is stored on the server (only if you sign in)

ItemContentsRetention
Account syncCoins, owned items, per-character outfits, per-device token count for this month (a number used for your level), account ID, display nameUntil you delete it
Chat roomRoom code, nickname, character, outfit, level, work motion (idle / working / done)Only while you are in the room (removed when you leave)
Chat messagesSender ID, nickname, message (up to 50 characters)Deleted by the sender after about 15 seconds — no history is kept

Never stored: your conversations with Claude, code, file names, what task you are working on, or project information. Chat partners only see a work motion (idle / working / done).

3. What stays on your device

  • Settings, shortcuts and shop state are kept on your device.
  • The token that keeps you signed in is stored on your device, encrypted with the macOS Keychain or Windows DPAPI.

4. Use and sharing

Information is used only to provide the features above. It is not used for advertising and is never sold or shared with third parties. Data is stored in Google Firebase (Authentication, Firestore, Realtime Database — chat is in the Singapore region).

5. Deleting your data and signing out

  • Sign out in the app's settings removes the sign-in from this device.
  • Delete server data in the app's settings deletes your synced account data from the server.
  • You can revoke Buni's access any time in your Google Account settings (myaccount.google.com/connections).

6. Contact

For privacy questions or deletion requests, please open an issue on GitHub Issues.

7. Changes

If this policy changes, the new version will be posted on this page with its effective date.
